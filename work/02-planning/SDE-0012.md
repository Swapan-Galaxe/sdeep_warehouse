# SDE-0012: Accessibility and error-recovery implementation

## Description

Ensure the UI meets WCAG 2.1 AA, is keyboard navigable, and provides clear error recovery for conversational failures.

## Acceptance Criteria

- UI passes keyboard navigation path. `[OPINION — accessibility spec]`
- Screen-reader labels are present for insight cards and citations. `[OPINION — accessibility spec]`
- Error messages explain the issue and suggest next actions. `[OPINION — accessibility spec]`
