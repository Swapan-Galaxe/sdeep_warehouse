# SDE-0009: Build recommendation engine with citations

## Description

Generate recommended next actions for leads and opportunities, including rationale, and allow users to accept, edit, or reject them.

## Acceptance Criteria

- Recommendations include action, owner, and due date. `[FACT — PRD R6]`
- Each recommendation cites source records and confidence. `[FACT — PRD R8]`
- User can accept, edit, or reject a recommendation. `[OPINION — wireframes]`
