## Target Standard

- WCAG 2.1 AA `[ASSUMPTION]`

## Key Requirements

| Area | Requirement |
|------|-------------|
| Keyboard | All interactive elements reachable and operable by keyboard alone `[OPINION]` |
| Screen Reader | Insight cards, confidence scores, and source links are announced with meaningful labels `[OPINION]` |
| Colour | Risk/priority levels use icon + text; colour is not the only indicator `[OPINION]` |
| Focus | Visible focus indicator on all focusable elements `[OPINION]` |
| Contrast | Text and icons meet WCAG 2.1 AA contrast ratios `[OPINION]` |
| Error Recovery | Conversational errors are explained in plain language with suggested next actions `[OPINION]` |

## Acceptance Criteria

- Accessibility audit passed before pilot release `[OPINION]`
- Keyboard navigation path documented `[OPINION]`
