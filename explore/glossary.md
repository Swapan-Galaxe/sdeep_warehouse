# Glossary

Shared terminology for the Salesforce Sales Intelligence Assistant Explore.

| Term | Definition |
|------|------------|
| Account | Customer or prospect organisation in Salesforce. |
| Activity | Historical sales touchpoint (call, email, meeting, task). |
| Agent | Specialist reasoning module that handles one domain (leads, opportunities, pricing, follow-up). |
| Closed Won / Closed Lost | Final opportunity states. |
| Contact | Person associated with an account. |
| Contact Role | Contact's relationship to an opportunity. |
| Forecast | Projected revenue for a period, aggregated from opportunities. |
| Insight | AI-generated prioritisation or risk output presented to a user. |
| Journey Map | Visualisation of a user's steps, pain points, and opportunities. |
| Lead | Unqualified prospect with potential interest. |
| Opportunity | Potential revenue deal tracked through stages. |
| Pipeline | Aggregate view of opportunities by stage and time. |
| Probability | Likelihood of an opportunity closing, often tied to stage. |
| RAG | Retrieval-Augmented Generation; semantic search over documents/conversations. |
| Recommendation | Suggested next action generated by the assistant. |
| ReAct Agent | Reasoning and acting agent that can use tools and iterate. |
| Stage | Opportunity lifecycle phase. |
| Task | Planned follow-up action. |
| Vector Store | Database for storing and querying embeddings. |
